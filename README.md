## Overview

Welcome to the official **Clash Project Website** repository (`itz`). Developed by **AniUi** in a lifetime collaboration with **Clash**, this site serves as the central showcase portal, release hub, and interactive documentation platform across the entire Clash ecosystem—including the **LastWave** high-resolution lossless music player.

The application leverages **React 19**, **TypeScript**, **Tailwind CSS v4**, **GSAP**, and **Framer Motion** to deliver modern web design with dynamic routing and interactive documentation.

---

## Tech Stack & Architecture

- **Frontend Framework:** React 19 (`react` & `react-dom`) with TypeScript
- **Build Tool & Bundler:** Vite 6 (`@tailwindcss/vite`)
- **Package Manager & Runtime:** Bun (`bun.lock`)
- **Animation & FX:** GSAP, Motion (`framer-motion`), and Lucide React Icons
- **Styling:** Tailwind CSS v4 (`index.css`)
- **API Services:** Google Gen AI (`@google/genai`), Express backend integration, and dynamic GitHub release tracking

---

## Pages & Routes

- 🏠 **Home Page (`/`):** Landing showcase canvas routing across Clash Project sub-sites.
- ⚡ **LastWave Hub (`/lastwave`):** Specialized web portal highlighting the high-resolution lossless music player & streaming app for Android. Features live release integration and spec breakdown.
- 🚧 **Clash Portal (`/Clash`):** Under-construction project portal featuring custom Japanese typography layouts (`项目`), banner alerts, and upcoming release patches.

---

## Features & UI Components

- 🎵 **LastWave Showcase:** Dedicated audio ecosystem section showcasing Studio Master FLAC support, dynamic APK downloads, and setup guides (`components/LastWaveDoc`, `LastWaveHowToUse`, `LastWaveSpec`).
- 🎨 **Custom Typography & Visual FX:** Dynamic animated components including `FoldText`, `StrokeText`, and gradient components (`KazumiGradient`).
- ⚡ **Automated Release Tracking:** Integrated GitHub API service (`services/githubRelease.ts`) to fetch latest release binaries and tags dynamically.
- 📱 **Adaptive Visual Layouts:** High-impact dark theme aesthetics optimized across desktop, tablet, and mobile displays.
